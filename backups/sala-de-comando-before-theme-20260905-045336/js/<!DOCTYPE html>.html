Modelagem Urbanística para Gleba de 20.000,00 m² (2,00 Hectares)

Projeto desenvolvido para tomada de decisão entre Chácaras Urbanas de Alto Padrão (1.000 m²) e Loteamento Residencial Minha Casa, Minha Vida (MCMV).
