Arquitetura

Três camadas, um repositório, tudo local com um comando.

apps/web
Front-end
Next.js 14 (App Router), TypeScript, Tailwind. Sidebar recolhível com estado em cookie. Server Components nas listagens, client nos formulários.
apps/api
Back-end
Node 20 com Fastify, Zod na validação, JWT em cookie httpOnly, senha em argon2. REST por recurso, camada de serviço isolada do ORM.
packages/db
Dados
PostgreSQL 16 com PostGIS para polígonos. Prisma dono das migrações. Row Level Security por imobiliária.
Estrutura de pastas
nexoterra/
├─ apps/
│  ├─ web/        console, login, sidebar recolhível
│  └─ api/        auth, imóveis, fazendas, armazéns, financeiro
├─ packages/
│  ├─ db/         Prisma schema + migrações
│  └─ ui/         componentes compartilhados
├─ docker-compose.yml   Postgres 16 + PostGIS
└─ .env.example
Fluxo de autenticação
O formulário envia usuário e senha para POST /auth/login. A API confere o hash argon2, emite JWT de 15 minutos e refresh de 7 dias, ambos em cookie httpOnly. O middleware do Next protege tudo sob /console e devolve ao login quando o token expira.

Banco de dados

Esquema criado vazio pelas migrações.

schema.sql
create extension if not exists pgcrypto;
create extension if not exists postgis;

create table users (
  id uuid primary key default gen_random_uuid(),
  username text unique not null,
  password text not null,              -- hash argon2
  role text not null default 'admin',
  created_at timestamptz default now()
);

create table agencies (                -- imobiliárias
  id uuid primary key default gen_random_uuid(),
  name text not null, cnpj text unique, creci text,
  city text, state char(2), manager text
);

create table properties (              -- imóveis
  id uuid primary key default gen_random_uuid(),
  agency_id uuid references agencies(id),
  title text not null, kind text,
  address text, city text, state char(2),
  area_m2 numeric(12,2), bedrooms int,
  registration text,                   -- matrícula
  price_cents bigint, status text default 'draft',
  lat numeric(9,6), lng numeric(9,6)
);

create table farms (                   -- fazendas
  id uuid primary key default gen_random_uuid(),
  name text not null, municipality text, state char(2),
  hectares numeric(12,2), registration text, car_code text,
  crop text, price_cents bigint, status text default 'draft',
  geom geometry(Polygon, 4674)
);

create table warehouses (              -- armazéns e silos
  id uuid primary key default gen_random_uuid(),
  name text not null, kind text,       -- silo | granel | convencional
  city text, state char(2), country text default 'BR',
  capacity_t numeric(12,2), occupancy_pct numeric(5,2),
  price_cents bigint, status text default 'draft'
);

create table leases (                  -- aluguéis
  id uuid primary key default gen_random_uuid(),
  asset_type text not null, asset_id uuid not null,
  tenant text not null, rent_cents bigint,
  due_day int, start_date date, end_date date,
  status text default 'active'
);

create table ledger (                  -- financeiro
  id uuid primary key default gen_random_uuid(),
  description text not null,
  kind text not null,                  -- receita | despesa
  category text, amount_cents bigint, entry_date date,
  asset_type text, asset_id uuid
);

create table market_quotes (
  id bigserial primary key,
  region text, commodity text,
  price numeric(14,4), currency char(3),
  observed_at timestamptz default now()
);

Rodar no VSCode

Do clone ao login funcionando. Requer Node 20, pnpm e Docker.

1
Abrir a pasta e instalar
No VSCode: File → Open Folder. Terminal integrado com Ctrl+`.
git clone <repo> nexoterra
cd nexoterra
pnpm install
2
Subir o PostgreSQL
Postgres 16 com PostGIS na porta 5432.
docker compose up -d db
cp .env.example .env
3
Criar tabelas e o usuário admin
As migrações criam o esquema vazio e um único usuário.
pnpm --filter db prisma migrate dev
pnpm --filter db bootstrap:admin   # admin / 123
4
Rodar front e back
API em :3001, console em :3000.
pnpm dev
5
Entrar e trocar a senha
Abra http://localhost:3000, entre com admin / 123 e troque a senha antes de expor o ambiente.
.env
DATABASE_URL="postgresql://nexo:nexo@localhost:5432/nexoterra"
JWT_SECRET="troque-este-valor"
API_URL="http://localhost:3001"
GOOGLE_MAPS_API_KEY=""
